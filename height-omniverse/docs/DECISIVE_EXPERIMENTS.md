# Decisive experiments (conceptual; preclinical; NO human self-experiment)

Ranked by value of information (see `results/tables/VALUE_OF_INFORMATION.csv`). Each: model, controls,
primary endpoint, required histology, maturity follow-up, falsification rule.

1. **Fusing-species final-length RCT for each velocity-only drug (vosoritide, CNP, FGFR3i).**
   Model: rabbit (fusion-capable), dosed across a defined window, washout to skeletal maturity.
   Controls: vehicle + pair-fed. Primary: mature femur/tibia length + time-to-fusion + serial bone age.
   Histology: full zonal. Falsify "velocity banks as height" if final length = control despite +velocity.
2. **Surrogate-calibration cohort: serial bone age + adult height for aromatase inhibitors.**
   Falsify AI adult-height benefit if attained height = control (already suggested by PMID 31024444).
3. **24-h zonal signaling time-course (cAMP/IHH/PTHrP) under each intervention** in a conventional
   physis — resolves expression≠activity and receptor-reserve questions.
4. **Human postnatal growth-plate protein/spatial map** (extend GSE288028) — zonal receptor protein,
   not mRNA, for GH/CNP/FGFR3/PTH1R axes.
5. **Reserve-clone lineage tracing under intermittent agonism** — does the intervention preserve or
   deplete the finite stem reserve (the twin's binding constraint)?
6. **Cartilage PK for systemic peptides** — closes the plasma→avascular-cartilage exposure gap.
