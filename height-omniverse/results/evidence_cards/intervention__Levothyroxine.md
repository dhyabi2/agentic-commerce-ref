# Levothyroxine  (intervention evidence card)

- **Modality:** thyroid hormone (T4)
- **Target:** thyroid hormone receptor
- **Action:** agonist
- **Approval:** approved
- **Route:** oral daily
- **PK:** t1/2 ~7 d (UNVERIFIED)

## Surrogate vs final height
- **congenital hypothyroidism (screened)** (observational cohorts): surrogate=catch-up velocity; adult height=normal adult height if treated early; incomplete if late; **translated=YES** [PMID 11580992]
